# ★★★ 最高宪法（2026-10-27 10:2x 作者 亲定，高于本文件其余一切）★★★

> 作者 原话：**「凡是改动的一律覆盖，改错了也认了。」**
>
> 「你要把错误的去掉。如果你改了，错误不去掉、不覆盖，下次很可能就用到错误的。
>   这是所有问题的根源，也就是项目不能推进的根本原因。」

## 宪法第一条：同一件事只许有一条路

改了做法 → **旧做法必须当场删除**，不许保留为"保命路 / 备用 / 待启用"。

以下行为 **一律禁止**（都算违反宪法）：

| 禁止 | 为什么（都是真事） |
|---|---|
| 留一个 `_旧` / `_备用` / `_bak` 函数在同一个文件里 | 下次 grep 到它、或某个分支走到它，用的就是错的那套 |
| 留一个开关（`判怪用模型`、`color_fallback` …）让新旧并存 | 开关只会被打开一次，然后就再没人记得它意味着旧路 |
| 旧代码"注释掉但留着" | 注释掉的代码和没写一样危险：它会被复制回去 |
| 新旧两套结果"取并集 / 取更宽松的那个" | 哪套错就放大哪套的错，且掩盖真因 |
| 出问题就加一条兜底逻辑而不删旧的 | 兜底越加越多，最终没人知道现在跑的是哪条 |

## 宪法第二条：改错了也不许偷偷回滚

方向错了 → **改方向并再覆盖一次**，不许把旧代码恢复成"第二条路"。
`git` 里能捞回历史就够了；**工作区里不许并存两代实现**。

## 宪法第三条：怎么算改完了

一次改动只有同时做到这三条才算完成：

1. **旧的那条路已经不存在**（不是注释掉、不是开关关掉，是删掉）；
2. **自检里有对应的守门员**（红了就拦住，不许开工）；
3. **这次改动落进 `证据\`**（改了什么、依据是什么、怎么退）。

三条缺一条 → 这次改动不算完成，不许宣布"好了"。

## 宪法第四条：依赖同理

换模型 / 换权重 / 换第三方库：**旧的那个文件删掉**。
留着旧权重 = 下次加载错文件 = 又是一轮"为什么不行"。
