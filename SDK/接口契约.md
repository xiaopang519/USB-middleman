# 接口契约（最核心）

> 层间传什么数据、什么格式、什么坐标系。
> 没有这份契约，层和层就得猜——猜错就崩。

## 感知层 → 决策层

```
内容：当前帧的目标列表
结构：[{"cx": int, "bar_y": int, "bar_w": int, "bar_h": int, "area": int}, ...]
坐标系：cx/bar_y 是客户区内屏幕像素（不是格子，不是屏幕绝对坐标）
单位：bar_w 是像素宽（不是剩余量百分比）
空值：没目标时返回 []（不是 None）
```

决策层拿到这份契约，知道：
- cx 是像素，要寻路得先除以 px_per_cell 换算成格子
- bar_w 是像素宽，残血判断要自己定阈值
- 不用猜格式

## 决策层 → 执行层

```
内容：要打的目标
结构：{"cx": int, "bar_y": int, "bar_w": int}（单个目标）或 None
坐标系：cx/bar_y 是客户区像素
```

执行层拿到这份契约，知道：
- 要把客户区坐标换算成屏幕坐标（+窗口偏移）才能点击
- None = 没目标，不点

## 执行层 → 行为层（Interception）

```
内容：屏幕坐标 + 动作
结构：click(x, y, name="left", hold_ms=100)
坐标系：x/y 是屏幕绝对坐标（像素）
换算：屏幕坐标 = 客户区坐标 + 客户区原点的屏幕坐标
```

Interception 内部还要再换算：屏幕像素 → 0~65535 绝对坐标。

## 校验层

```
输入：当前帧 PIL Image
输出：bool（True=动了, False=没动可能卡死）
```

校验层不关心目标在哪，只管"画面变没变"。

## 系统层 · 控制类

| 信号 | 谁触发 | 传给谁 | 效果 |
|---|---|---|---|
| start | 面板/自动启动 | FullBot | 找窗口+启动主循环 |
| stop | 面板停止按钮 | FullBot | running=False，下一帧退出 |
| emergency | 热键 Ctrl+Alt+Q | FullBot | 立即停 |
| toggle_pause | 热键 Ctrl+Alt+P | FullBot | 切换暂停，暂停时不碰鼠标 |

约束：
1. 热键优先级 > 按钮优先级（抢鼠标时靠热键）
2. 主循环每帧检查 running 和 paused
3. paused=True 时完全不碰鼠标

## 系统层 · 配置管理

| 配置项 | 类型 | 默认 | 生效方式 |
|---|---|---|---|
| target_keyword | str | "" | 下次找窗口 |
| loop_interval | float | 0.3 | 立即（每帧读） |
| mouse_dev | int | 11 | 重启 |
| hotkey_stop | str | ctrl+alt+q | 重启 |
| hotkey_pause | str | ctrl+alt+p | 重启 |
| lock_timeout | float | 45.0 | 立即 |

## 系统层 · 异常恢复

| 异常 | 级别 | 处理 |
|---|---|---|
| 抓帧返回 None | 可恢复 | 跳过这帧 |
| 连续 N 次抓帧失败 | 致命 | 停止 + 提示 |
| 识别/决策/执行报错 | 可恢复 | 跳过这帧 |
| 窗口丢失 | 致命 | 停止 |
| 未捕获异常 | 致命 | 停止 + 记日志 |

接口：`handle(exception, layer_name) → "skip" 或 "stop"`

## 坐标格式速查

| 格式 | 范围 | 谁用 |
|---|---|---|
| 客户区坐标 | 0~窗口宽/高 | 感知层输出、决策层用 |
| 屏幕坐标 | 0~屏幕宽/高（跨屏） | 执行层点击 |
| 格子坐标 | 0~地图宽/高 | 寻路（本 SDK 没实现） |
| 归一化 | 0~1 浮点 | YOLO 输出（本 SDK 没用） |
| 绝对坐标 | 0~65535 | Interception 内部 |

换算链：
```
客户区(975,260) → +窗口偏移 → 屏幕(2875,488) → *65535/屏幕宽 → 绝对坐标
客户区(975,260) → ÷px_per_cell → 格子(20,5)
```

## 一句话

**接口契约 = 层间数据的说明书。没它，层和层就得猜，猜错就崩。**
